# shift-pilot-php

Pilote de test SHIFT/Paperclip — facturation avec TGC (Polynésie française).

## Stack

- PHP >= 8.0, Composer
- Monolog (journalisation)
- PHPUnit (tests) : `composer install` puis `composer test`

## Remarques

- Le fichier `composer.lock` n'est pas versionné à ce jour.
- La journalisation repose sur l'API Monolog actuellement en place.
